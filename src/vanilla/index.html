Google Sheet API Connection

Configure your live Google Apps Script Web App URL or test mock data.

Leave blank or click "Use Demo Data" to test with built-in dataset.

How to get your Web App URL in 30 seconds:
  1. Create a Google Sheet with tabs: Settings, Menu, about, Products, Gallery, Article and update, send Message
  2. Click Extensions > Apps Script and paste the provided Code.gs
  3. Run setupInitialSheets() once to auto-create all columns & data
  4. Click Deploy > New Deployment > Select Web App > Access: Anyone
